## 🔄 数据转换流程

```
Task 域对象（驼峰命名）
  ↓
convertToTaskListItemResponse()
  ↓
TaskListItemResponse DTO（驼峰命名）
  ↓
Jackson 序列化（默认驼峰命名）
  ↓
JSON 响应（驼峰命名）
```

## ⚠️ 注意事项

1. **ID 字段**:
   - 使用内部类 `IdValue` 实现 `{ value: ... }` 格式
   - 序列化后：`"id": { "value": 1 }`

2. **状态字段**:
   - `TaskStatus` 枚举通过 `.name()` 转换为字符串
   - 返回："PENDING", "COMPLETED", "DRAFT", "FAILED", "IN_PROGRESS"

3. **日期字段**:
   - `LocalDateTime` 转换为 ISO 8601 格式字符串
   - 格式：`"2025-07-07T10:42:00"`
   - null 值会被忽略（`@JsonInclude(NON_NULL)`）

4. **空值处理**:
   - 使用 `@JsonInclude(JsonInclude.Include.NON_NULL)` 忽略 null 字段
   - 减少响应体积，提高可读性
