## ⚠️ 可能遇到的问题

### 1. 数据库连接失败

**错误**: `Communications link failure` 或 `Access denied`

**解决**:
- 检查 MySQL 服务是否启动
- 检查数据库用户名密码
- 检查数据库是否存在

### 2. MyBatis Mapper 找不到

**错误**: `No bean named 'xxxMapper' available`

**解决**: 确保 MyBatisConfig 的 @MapperScan 配置正确

### 3. Bean 注入失败

**错误**: `Could not autowire`

**解决**: 检查包扫描路径是否正确

### 4. Clerk Token 验证失败

**错误**: `Invalid token`

**解决**: 
- 配置正确的 Clerk Secret Key
- 或暂时跳过认证（修改拦截器）

### 5. Python 后端调用失败

**错误**: `Connection refused`

**解决**: 
- 确保 Python 后端运行在 http://localhost:8000
- 或暂时注释掉 Python 后端调用代码
