## 🚀 快速启动

### 方式1: 本地环境（使用 Docker MySQL）

```bash
# 1. 启动 MySQL（在 docker 目录下）
cd docker
docker-compose up -d mysql

# 2. 等待 MySQL 初始化（约 10-30 秒）
sleep 30

# 3. 启动 SpringBoot 后端（在 studyagent-backend 目录下）
cd ../studyagent-backend/agent-start
SPRING_PROFILES_ACTIVE=local mvn spring-boot:run
```

**数据库连接信息**:
- Host: `localhost`
- Port: `13306` (Docker MySQL 映射端口)
- Database: `studyagent`
- Username: `studyagent`
- Password: `studyagent2024`

### 方式2: Docker 环境

```bash
# 1. 确保 MySQL 已启动（在 docker 目录下）
cd docker
docker-compose ps mysql

# 如果未启动，启动 MySQL
docker-compose up -d mysql

# 2. 启动 SpringBoot 后端（在 studyagent-backend 目录下）
cd ../studyagent-backend
docker-compose up -d

# 3. 查看日志
docker-compose logs -f springboot-backend
```

**数据库连接信息**:
- Host: `mysql` (Docker 服务名)
- Port: `3306`
- Database: `studyagent`
- Username: `studyagent`
- Password: `studyagent2024`

## ⚠️ 常见问题

### 问题1: 数据库连接失败

**错误**: `Communications link failure`

**解决方案**:
1. 检查 MySQL 是否运行: `docker-compose ps mysql`
2. 检查端口是否正确（本地 13306，Docker 3306）
3. 等待 MySQL 完全初始化（首次启动需要 10-30 秒）

### 问题2: 认证失败

**错误**: `Access denied for user 'studyagent'@'%'`

**解决方案**:
1. 确认用户名密码正确（studyagent/studyagent2024）
2. 检查 MySQL 用户权限
3. 确认数据库已初始化（执行了 init.sql）

### 问题3: Docker 网络问题

**错误**: `Unknown host: mysql`

**解决方案**:
1. 确保 SpringBoot 后端和 MySQL 在同一个网络
2. 检查 `docker-compose.yml` 中的网络配置
3. 创建网络: `docker network create studyagent-network`

## 📊 配置文件优先级

SpringBoot 配置加载顺序（优先级从高到低）:
1. 环境变量
2. `application-{profile}.yml`
3. `application.yml`

**示例**:
```bash
# 使用 local profile
SPRING_PROFILES_ACTIVE=local mvn spring-boot:run

# 使用 docker profile
SPRING_PROFILES_ACTIVE=docker mvn spring-boot:run

# 使用 dev profile
SPRING_PROFILES_ACTIVE=dev mvn spring-boot:run
```
