## 🎯 架构特点

1. **DDD 分层架构**: 清晰的职责分离
2. **依赖倒置**: Service 层定义接口，Infra 层实现
3. **易于测试**: 各层可独立测试
4. **易于扩展**: 新增功能只需在对应层添加代码
5. **符合规范**: 遵循 Spring Boot 和 DDD 最佳实践

## ⚠️ 注意事项

1. **Python 后端**: 需要确保 Python 后端提供 `/v1/task/execute` 接口
2. **数据库**: 确保数据库表结构与 Entity 一致
3. **Clerk**: 需要配置 Clerk Secret Key
4. **Stripe**: 需要配置 Stripe Secret Key 和 Price IDs
5. **文件存储**: 确保存储目录有写入权限
