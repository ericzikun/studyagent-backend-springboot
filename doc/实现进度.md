## 📝 注意事项

1. **数据库字段映射**: 确保 Entity 字段与数据库表结构一致
2. **时间字段**: 使用 LocalDateTime，需要配置 MyBatis 类型处理器
3. **JSON 字段**: format 字段需要 JSON 序列化/反序列化
4. **Clerk 集成**: 当前使用 HTTP 调用，建议后续使用 Clerk Java SDK
5. **Python 后端调用**: 需要确保 Python 后端提供 `/v1/task/execute` 接口
