# SpringBoot 后端快速开始指南

## 📋 前置要求

- JDK 17+
- Maven 3.6+
- MySQL 8.0+
- Python 后端运行在 `http://localhost:8000`

## 🚀 快速开始

### 1. 配置数据库

确保 MySQL 数据库已创建并执行了初始化 SQL（使用项目中的 `docker/init.sql`）

### 2. 配置环境变量

创建 `.env` 文件或设置环境变量：

```bash
# 数据库配置
DB_USERNAME=root
DB_PASSWORD=your_password

# Clerk 配置
CLERK_SECRET_KEY=sk_test_xxx
CLERK_PUBLISHABLE_KEY=pk_test_xxx

# Stripe 配置
STRIPE_SECRET_KEY=sk_test_xxx
STRIPE_PUBLISHABLE_KEY=pk_test_xxx
STRIPE_WEBHOOK_SECRET=whsec_xxx
STRIPE_PRICE_STARTER=price_xxx
STRIPE_PRICE_PRO=price_xxx
STRIPE_PRICE_ACADEMIC=price_xxx

# Python 后端配置
PYTHON_BACKEND_URL=http://localhost:8000
```

### 3. 构建项目

```bash
cd studyagent-backend
mvn clean install
```

### 4. 运行应用

```bash
cd agent-start
mvn spring-boot:run
```

或者：

```bash
java -jar agent-start/target/agent-start-1.0.0-SNAPSHOT.jar
```

### 5. 访问 API

- **API 文档**: http://localhost:8080/swagger-ui.html
- **健康检查**: http://localhost:8080/health
- **API 基础地址**: http://localhost:8080

## 📝 接口测试

### 健康检查

```bash
curl http://localhost:8080/health
```

### 获取用户信息（需要 Clerk Token）

```bash
curl -X GET "http://localhost:8080/v1/auth/me" \
  -H "Authorization: Bearer <clerk_token>"
```

### 上传文件

```bash
curl -X POST "http://localhost:8080/v1/file/upload" \
  -H "Content-Type: application/json" \
  -d '{
    "raw_body": "<base64_encoded_file_content>"
  }'
```

### 提交任务（需要登录）

```bash
curl -X POST "http://localhost:8080/v1/task/submit" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <clerk_token>" \
  -d '{
    "task_title": "测试任务",
    "task_desc": "这是一个测试任务",
    "subject": 1,
    "academic_level": 2,
    "priority_level": 2,
    "due_date": "2024-12-31T23:59:59",
    "format": [1, 2],
    "citation_style": 1,
    "page_length": 10,
    "special_instructions": ""
  }'
```

## 🔧 开发模式

### 使用开发环境配置

```bash
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

### 启用热重载

Spring Boot DevTools 已配置，修改代码后会自动重启。

## ⚠️ 注意事项

1. **数据库连接**: 确保 MySQL 服务已启动
2. **Python 后端**: 确保 Python 后端运行在 `http://localhost:8000`
3. **Clerk Token**: 前端需要提供有效的 Clerk Token
4. **文件存储**: 确保存储目录有写入权限

## 🐛 常见问题

### 1. 数据库连接失败

检查 `application.yml` 中的数据库配置，确保 MySQL 服务已启动。

### 2. 模块找不到

确保已执行 `mvn clean install` 安装所有模块到本地仓库。

### 3. 端口被占用

修改 `application.yml` 中的 `server.port` 配置。
