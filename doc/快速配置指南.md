# 快速配置指南 - 本地启动

## 🎯 最简单的配置方式

### 步骤1: 创建 .env 文件

在 `studyagent-backend` 目录下创建 `.env` 文件：

```bash
cd studyagent-backend
cp env.example .env
```

### 步骤2: 编辑 .env 文件

使用你喜欢的编辑器打开 `.env` 文件，填入实际值：

```bash
# 数据库配置（必需）
DB_HOST=localhost
DB_PORT=13306
DB_NAME=studyagent
DB_USERNAME=studyagent
DB_PASSWORD=studyagent2024

# Clerk 配置（如果需要认证功能）
CLERK_SECRET_KEY=sk_test_your_actual_key_here
CLERK_PUBLISHABLE_KEY=pk_test_your_actual_key_here

# Stripe 配置（如果需要支付功能）
STRIPE_SECRET_KEY=sk_test_your_actual_key_here
STRIPE_PUBLISHABLE_KEY=pk_test_your_actual_key_here
STRIPE_WEBHOOK_SECRET=whsec_your_actual_secret_here

# Python 后端配置（如果需要任务执行）
PYTHON_BACKEND_URL=http://localhost:8000
```

### 步骤3: 启动应用

```bash
cd agent-start
SPRING_PROFILES_ACTIVE=local mvn spring-boot:run
```

**完成！** Spring Boot 会自动读取 `.env` 文件中的环境变量。

```
│       └── application-prod.yml         # 生产环境配置
```

## 🔧 配置优先级

Spring Boot 按以下顺序加载配置（优先级从高到低）：

1. **环境变量** (最高优先级)
2. `.env` 文件
3. `application-{profile}.yml`
4. `application.yml` (最低优先级)

**示例**:
- 如果 `.env` 中设置了 `DB_HOST=localhost`
- 但环境变量中设置了 `DB_HOST=192.168.1.100`
- 最终会使用 `192.168.1.100`（环境变量优先级更高）

## 💡 推荐做法

### 开发环境
- ✅ 使用 `.env` 文件存储所有配置
- ✅ 将 `.env` 添加到 `.gitignore`（已添加）
- ✅ 提交 `env.example` 作为模板

### 生产环境
- ✅ 使用环境变量或配置中心
- ✅ 不要使用 `.env` 文件

---

## ⚠️ 注意事项

1. **`.env` 文件不要提交到 Git**
   - 已添加到 `.gitignore`
   - 包含敏感信息（密钥、密码）

2. **使用 `env.example` 作为模板**
   - 可以提交到 Git
   - 不包含实际密钥

3. **不同环境使用不同配置**
   - 本地开发: `.env` + `application-local.yml`
   - Docker: `application-docker.yml` + 环境变量
   - 生产: 环境变量或配置中心

## 🚀 快速测试

### 最小配置测试（只配置数据库）

```bash
# 1. 创建最小 .env
cat > studyagent-backend/.env << EOF
DB_HOST=localhost
DB_PORT=13306
DB_NAME=studyagent
DB_USERNAME=studyagent
DB_PASSWORD=studyagent2024
EOF

# 2. 启动应用
cd studyagent-backend/agent-start
SPRING_PROFILES_ACTIVE=local mvn spring-boot:run

# 3. 测试健康检查
curl http://localhost:8080/health
```

如果看到 `"database": "connected"`，说明配置成功！
