## ⚠️ 注意事项

1. **密码大小写敏感**:
   - 确保密码完全匹配（包括大小写）
   - 如果密码是 `Fzk971228`（大写 F），请更新 `.env` 文件

2. **数据库必须存在**:
   - 确保 `studyagent` 数据库已创建
   - 如果不存在，需要先创建：
   ```sql
   CREATE DATABASE IF NOT EXISTS studyagent CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

3. **用户权限**:
   - 确保 `root` 用户有访问 `studyagent` 数据库的权限
   - 如果权限不足，可以授权：
   ```sql
   GRANT ALL PRIVILEGES ON studyagent.* TO 'root'@'localhost';
   FLUSH PRIVILEGES;
   ```

4. **端口配置**:
   - 本地 MySQL 默认端口是 `3306`
   - 如果使用 Docker MySQL，端口可能是 `13306`（映射端口）
   - 根据实际情况调整 `DB_PORT` 环境变量
