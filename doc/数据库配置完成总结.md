## 🔧 配置特点

### 本地环境
- **数据库连接**: `localhost:13306`（Docker MySQL 映射端口）
- **文件存储**: 相对路径 `./storage`
- **Python 后端**: `http://localhost:8000`

### Docker 环境
- **数据库连接**: `mysql:3306`（Docker 服务名）
- **文件存储**: 绝对路径 `/app/storage`
- **Python 后端**: `http://backend:8000`（Docker 服务名）

## 🚀 快速启动

### 本地环境

```bash
# 1. 启动 MySQL
cd docker
docker-compose up -d mysql

# 2. 等待 MySQL 初始化
sleep 30

# 3. 启动 SpringBoot 后端
cd ../studyagent-backend/agent-start
SPRING_PROFILES_ACTIVE=local mvn spring-boot:run
```

### Docker 环境

```bash
# 1. 确保 MySQL 已启动
cd docker
docker-compose ps mysql

# 2. 启动 SpringBoot 后端
cd ../studyagent-backend
docker-compose up -d

# 3. 查看日志
docker-compose logs -f springboot-backend
```

## ✅ 验证

启动后访问健康检查：

```bash
curl http://localhost:8080/health
```

如果看到 `"database": "connected"`，说明数据库连接成功！

## 📝 注意事项

1. **MySQL 必须先启动**: SpringBoot 后端依赖 MySQL 服务
2. **网络配置**: Docker 环境需要 `studyagent-network` 网络
3. **端口映射**: 本地环境使用 13306，Docker 环境使用 3306
4. **初始化时间**: MySQL 首次启动需要 10-30 秒初始化
