# 数据库配置说明

## 📋 配置概览

SpringBoot 后端支持两种环境：
1. **本地环境** - 直接运行在本地机器上
2. **Docker 环境** - 运行在 Docker 容器中

## 🔧 本地环境配置

### 方式1: 使用 Docker 启动的 MySQL（推荐）

如果使用 `docker/docker-compose.yml` 启动 MySQL：

```bash
# 1. 启动 MySQL（在 docker 目录下）
cd docker
docker-compose up -d mysql

# 2. MySQL 端口映射为 13306:3306
# 所以本地连接端口是 13306
```

**配置** (`application-local.yml` 或环境变量):
```yaml
DB_HOST=localhost
DB_PORT=13306
DB_NAME=studyagent
DB_USERNAME=studyagent
DB_PASSWORD=studyagent2024
```

### 方式2: 本地安装的 MySQL

如果本地直接安装了 MySQL：

```yaml
DB_HOST=localhost
DB_PORT=3306
DB_NAME=studyagent
DB_USERNAME=root  # 或你的 MySQL 用户名
DB_PASSWORD=your_password
```

### 启动应用（本地环境）

```bash
# 使用本地配置
cd agent-start
mvn spring-boot:run -Dspring-boot.run.profiles=local

# 或设置环境变量
export SPRING_PROFILES_ACTIVE=local
mvn spring-boot:run
```

## 🐳 Docker 环境配置

### 方式1: 使用现有的 docker-compose.yml（推荐）

如果已经有 `docker/docker-compose.yml` 运行 MySQL：

```bash
# 1. 确保 MySQL 服务正在运行
cd docker
docker-compose ps mysql

# 2. 在 studyagent-backend 目录下启动 SpringBoot 后端
cd ../studyagent-backend
docker-compose up -d
```

**配置说明**:
- SpringBoot 后端会连接到 `mysql` 服务（Docker Compose 服务名）
- 数据库配置从环境变量读取
- 使用 `application-docker.yml` 配置

### 方式2: 独立启动（需要先启动 MySQL）

```bash
# 1. 确保 MySQL 服务在 studyagent-network 网络中
cd docker
docker-compose up -d mysql

# 2. 启动 SpringBoot 后端
cd ../studyagent-backend
docker-compose up -d
```

## 📝 环境变量配置

### 创建 .env 文件

```bash
cd studyagent-backend
cp .env.example .env
# 编辑 .env 文件，修改数据库配置
```

### 环境变量说明

| 变量名 | 本地环境 | Docker 环境 | 说明 |
|--------|---------|------------|------|
| `DB_HOST` | `localhost` | `mysql` | 数据库主机 |
| `DB_PORT` | `13306` 或 `3306` | `3306` | 数据库端口 |
| `DB_NAME` | `studyagent` | `studyagent` | 数据库名 |
| `DB_USERNAME` | `studyagent` | `studyagent` | 数据库用户名 |
| `DB_PASSWORD` | `studyagent2024` | `studyagent2024` | 数据库密码 |

## ⚠️ 常见问题

### 问题1: 连接被拒绝

**错误**: `Communications link failure`

**解决方案**:
1. 检查 MySQL 服务是否运行
2. 检查端口是否正确（本地 13306，Docker 3306）
3. 检查防火墙设置

### 问题2: 认证失败

**错误**: `Access denied for user`

**解决方案**:
1. 检查用户名密码是否正确
2. 确认用户有访问数据库的权限
3. 检查 MySQL 用户是否允许从该主机连接

### 问题3: Docker 网络问题

**错误**: `Unknown host: mysql`

**解决方案**:
1. 确保 SpringBoot 后端和 MySQL 在同一个 Docker 网络中
2. 检查 `docker-compose.yml` 中的 `networks` 配置
3. 使用 `docker network ls` 查看网络列表

## 📊 配置文件优先级

SpringBoot 会按以下顺序加载配置：

1. `application.yml` - 基础配置
2. `application-{profile}.yml` - 环境特定配置
3. 环境变量 - 最高优先级

**示例**:
```bash
# 使用 local profile
SPRING_PROFILES_ACTIVE=local mvn spring-boot:run

# 使用 docker profile
SPRING_PROFILES_ACTIVE=docker mvn spring-boot:run
```

## 🚀 快速启动

### 本地环境（使用 Docker MySQL）

```bash
# 1. 启动 MySQL
cd docker
docker-compose up -d mysql

# 2. 等待 MySQL 初始化（约 10-30 秒）
sleep 30

# 3. 启动 SpringBoot 后端
cd ../studyagent-backend/agent-start
SPRING_PROFILES_ACTIVE=local mvn spring-boot:run
```

### Docker 环境

```bash
# 1. 确保 MySQL 已启动
cd docker
docker-compose ps mysql

# 2. 启动 SpringBoot 后端
cd ../studyagent-backend
docker-compose up -d

# 3. 查看日志
docker-compose logs -f springboot-backend
```
