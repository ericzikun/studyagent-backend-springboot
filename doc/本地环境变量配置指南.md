# 本地环境变量配置指南

## 📋 配置方式（推荐顺序）

### 方式1: 使用 .env 文件（推荐）⭐

Spring Boot 2.4+ 原生支持 `.env` 文件，最简单方便。

#### 步骤1: 创建 .env 文件

```bash
cd studyagent-backend
cp env.example .env
```

#### 步骤2: 编辑 .env 文件

```bash
# 数据库配置
DB_HOST=localhost
DB_PORT=13306
DB_NAME=studyagent
DB_USERNAME=studyagent
DB_PASSWORD=studyagent2024

# Clerk 配置（从 Clerk Dashboard 获取）
CLERK_SECRET_KEY=sk_test_your_actual_key_here
CLERK_PUBLISHABLE_KEY=pk_test_your_actual_key_here
CLERK_API_URL=https://api.clerk.dev/v1

# Stripe 配置（从 Stripe Dashboard 获取）
STRIPE_SECRET_KEY=sk_test_your_actual_key_here
STRIPE_PUBLISHABLE_KEY=pk_test_your_actual_key_here
STRIPE_WEBHOOK_SECRET=whsec_your_actual_secret_here
# Stripe Price ID 配置（重要：必须是 Price ID 或 Product ID，不能是数字价格）
# 格式1: Price ID（推荐）- price_xxxxx（例如：price_1ABC123def456GHI789）
# 格式2: Product ID - prod_xxxxx（例如：prod_ThSpkBw4Rny4XM），会自动查找其下的第一个 Price
# ❌ 错误示例: 4.99（这是价格金额，不是 Price ID）
STRIPE_PRICE_STARTER=price_your_starter_price_id
STRIPE_PRICE_PRO=price_your_pro_price_id
STRIPE_PRICE_ACADEMIC=price_your_academic_price_id

# Python 后端配置
PYTHON_BACKEND_URL=http://localhost:8000

# 文件存储配置（相对于项目根目录 studyagent-backend）
# 注意：由于启动目录是 agent-start，使用 ../storage 指向项目根目录
FILE_STORAGE_PATH=../storage
FILE_UPLOAD_PATH=../storage/uploads
FILE_OUTPUT_PATH=../storage/outputs

# 支付配置
PAYMENT_SUCCESS_URL=http://localhost:3000/success
PAYMENT_CANCEL_URL=http://localhost:3000/cancel
```

#### 步骤3: 启动应用

```bash
cd agent-start
SPRING_PROFILES_ACTIVE=local mvn spring-boot:run
```

**注意**: Spring Boot 2.4+ 会自动读取项目根目录的 `.env` 文件。

### 方式2: 使用 application-local.yml（适合固定配置）

如果配置相对固定，可以直接修改 `application-local.yml`。

#### 编辑文件

```bash
vim agent-start/src/main/resources/application-local.yml
```

#### 添加配置

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:13306/studyagent?...
    username: studyagent
    password: studyagent2024

# Clerk 配置
clerk:
  secret-key: sk_test_your_actual_key_here
  publishable-key: pk_test_your_actual_key_here
  api-url: https://api.clerk.dev/v1

# Stripe 配置
stripe:
  secret-key: sk_test_your_actual_key_here
  publishable-key: pk_test_your_actual_key_here
  webhook-secret: whsec_your_actual_secret_here
  price:
    starter: price_your_starter_price_id
    pro: price_your_pro_price_id
    academic: price_your_academic_price_id

# Python 后端配置
python-backend:
  url: http://localhost:8000

# 文件存储配置
file:
  storage:
    base-path: ./storage
    upload-path: ./storage/uploads
    output-path: ./storage/outputs

# 支付配置
payment:
  success-url: http://localhost:3000/success
  cancel-url: http://localhost:3000/cancel
```

### 方式4: 使用 IDE 配置（IntelliJ IDEA / VS Code）

#### IntelliJ IDEA

1. 打开 `Run` → `Edit Configurations`
2. 选择或创建 Spring Boot 配置
3. 在 `Environment variables` 中添加：
   ```
   DB_HOST=localhost
   DB_PORT=13306
   DB_USERNAME=studyagent
   DB_PASSWORD=studyagent2024
   CLERK_SECRET_KEY=sk_test_your_key
   ...
   ```
4. 在 `Active profiles` 中添加：`local`

#### VS Code

创建 `.vscode/launch.json`:

```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "java",
      "name": "Spring Boot - Local",
      "request": "launch",
      "mainClass": "com.studyagent.start.StudyAgentApplication",
      "projectName": "agent-start",
      "args": "",
      "env": {
        "SPRING_PROFILES_ACTIVE": "local",
        "DB_HOST": "localhost",
        "DB_PORT": "13306",
        "DB_USERNAME": "studyagent",
        "DB_PASSWORD": "studyagent2024",
        "CLERK_SECRET_KEY": "sk_test_your_key",
        "STRIPE_SECRET_KEY": "sk_test_your_key"
      }
    }
  ]
}
```

## 🎯 推荐配置方式

### 开发环境推荐：`.env` 文件

**优点**:
- ✅ 简单方便，一个文件搞定
- ✅ 不提交到 Git（已添加到 .gitignore）
- ✅ 支持所有环境变量
- ✅ Spring Boot 原生支持

**步骤**:
```bash
# 1. 复制示例文件
cp env.example .env

# 2. 编辑 .env，填入实际值
vim .env

# 3. 启动应用
cd agent-start
SPRING_PROFILES_ACTIVE=local mvn spring-boot:run
```

## 📝 环境变量列表

### 必需配置（数据库）

| 变量名 | 说明 | 示例值 |
|--------|------|--------|
| `DB_HOST` | 数据库主机 | `localhost` |
| `DB_PORT` | 数据库端口 | `13306` |
| `DB_NAME` | 数据库名 | `studyagent` |
| `DB_USERNAME` | 数据库用户名 | `studyagent` |
| `DB_PASSWORD` | 数据库密码 | `studyagent2024` |

### 可选配置（外部服务）

| 变量名 | 说明 | 示例值 | 必需 |
|--------|------|--------|------|
| `CLERK_SECRET_KEY` | Clerk Secret Key | `sk_test_xxx` | ⚠️ 需要认证时 |
| `CLERK_PUBLISHABLE_KEY` | Clerk Publishable Key | `pk_test_xxx` | ⚠️ 需要认证时 |
| `STRIPE_SECRET_KEY` | Stripe Secret Key | `sk_test_xxx` | ⚠️ 需要支付时 |
| `STRIPE_PUBLISHABLE_KEY` | Stripe Publishable Key | `pk_test_xxx` | ⚠️ 需要支付时 |
| `STRIPE_WEBHOOK_SECRET` | Stripe Webhook Secret | `whsec_xxx` | ⚠️ 需要支付时 |
| `PYTHON_BACKEND_URL` | Python 后端地址 | `http://localhost:8000` | ⚠️ 需要任务执行时 |

## 🔒 安全注意事项

### 1. 不要提交敏感信息

确保 `.env` 文件已添加到 `.gitignore`:

```bash
# 检查 .gitignore
cat .gitignore | grep .env

# 如果没有，添加
echo ".env" >> .gitignore
echo ".env.local" >> .gitignore
```

### 2. 使用示例文件

- ✅ `env.example` - 可以提交到 Git（不包含敏感信息）
- ❌ `.env` - 不要提交到 Git（包含实际密钥）

### 3. 不同环境使用不同配置

- 开发环境: `.env.local` 或 `.env.dev`
- 生产环境: 使用环境变量或配置中心

## 🚀 快速开始

### 最小配置（只配置数据库）

```bash
# 1. 创建 .env 文件
cat > studyagent-backend/.env << EOF
DB_HOST=localhost
DB_PORT=13306
DB_NAME=studyagent
DB_USERNAME=studyagent
DB_PASSWORD=studyagent2024
EOF

# 2. 启动应用
cd studyagent-backend/agent-start
SPRING_PROFILES_ACTIVE=local mvn spring-boot:run
```

### 完整配置（包含所有服务）

```bash
# 1. 复制示例文件
cd studyagent-backend
cp env.example .env

# 2. 编辑 .env，填入实际值
vim .env  # 或使用你喜欢的编辑器

# 3. 启动应用
cd agent-start
SPRING_PROFILES_ACTIVE=local mvn spring-boot:run
```
