数据定时播报群

### 3.1 日报

### 触发时机

每天北京时间 12:00 推送，统计范围：前一天北京时间 00:00 - 24:00

---

### 字段口径

| 字段  | 口径说明 |
| --- | --- |
| DAU | 统计日内有登录行为的去重用户数 |
| 新用户注册数 | 统计日内完成注册的用户数 |
| 新用户来源分布 | 新注册用户的首访来源domain，取Top5，格式：google.com · XX人（XX%） |
| 任务创建数 | 统计日内用户点击确认开始任务的次数 |
| 任务成功数 | 统计日内任务状态变为Completed的数量 |
| 任务失败数 | 统计日内任务状态变为Fail的数量 |
| 任务成功比例 | 任务成功数 ÷ 任务创建数，保留一位小数，格式：XX.X% |
| 平均执行时长 | 统计日内所有Completed任务的执行时长均值，格式：XX分XX秒 |
| 注册→创建任务转化率 | 统计日内有创建任务行为的用户数 ÷ 统计日内新注册用户数，保留一位小数 |
| 创建→完成转化率 | 统计日内任务成功数 ÷ 任务创建数，保留一位小数 |
| 完成→进入编辑页转化率 | 统计日内进入编辑页的任务数 ÷ 任务成功数，保留一位小数 |
| 进入编辑页→消费内容转化率 | 统计日内有点击Download或复制文本行为的任务数 ÷ 进入编辑页的任务数，保留一位小数 |
| 当日反馈数 | 统计日内三个功能反馈提交总数，按功能分开展示 |
| Assignment平均评分 | 统计日内Assignment反馈的星级均值，保留一位小数 |
| AI Detection好评率 | 统计日内AI Detection反馈中好评数 ÷ 总反馈数，保留一位小数 |
| Humanizer好评率 | 统计日内Humanizer反馈中好评数 ÷ 总反馈数，保留一位小数 |
| 同期对比**（放在每个字段后面）** | 所有指标对比上周同一天数据，格式：+XX% / -XX%。若上周同期数据为0则显示：无基准 |

## 周报

### 触发时机

每周日北京时间 12:00 推送，统计范围：上周日 00:00 - 本周日 00:00 (BJT)

---

### 字段口径

1. 访问、任务、转化、反馈类字段口径**同日报，统计维度改为周维度，同期对比改为对比上一自然周数据。**

2. 付费类新增字段如下：


| 字段  | 口径说明 |
| --- | --- |
| 当周收入 | 统计周内三个功能付款成功金额总和 |
| 付费用户数 | 统计周内有付款成功记录的去重用户数 |
| Assignment付费订单数 | 统计周内Assignment付款成功订单数，**按SKU分布展示：1x2.99￥，2x4.99￥xxx** |
| AI Detection付费订单数 | 统计周内AI Detection付款成功订单数，按SKU分布展示 |
| Humanizer付费订单数 | 统计周内Humanizer付款成功订单数，按SKU分布展示 |
| 各功能付费总额分布 | 三个功能各自的付款成功金额总和及占比 |
| 新付费用户占比 | 统计周内首次付费用户数 ÷ 付费用户数，保留一位小数 |
| 复购用户占比 | 统计周内有复购行为用户数 ÷ 付费用户数，保留一位小数 |
| **同期对比** | 所有指标对比上一自然周数据，格式：+XX% / -XX%。若上周数据为0显示：无基准 |

---
