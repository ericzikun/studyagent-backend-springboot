# 地区差异化定价：简版技术方案

版本：2026-10-18 r5（Study Pass全量固定金额已补齐）。基于前后端 `feat/billing-brazil-pricing`；本次仅修正文档和交接价格草案，尚未实施扩展代码、写入Stripe或部署。

## 1. 已确认需求

第一组10地区、第二组53地区全部使用新金额，共63地区；Pro统一使用“新 Pro”月付／年付价格。唯一当期保旧价例外：本次需求确认时线上已购买Pro的用户，当前已付周期保留旧金额，下个付费周期切新价。

分组只保留原表分类，不作为是否采用新价格的条件。巴西原属第二组，与美国、印度、日本等其余第二组地区适用同一新价要求。具体金额见[两组完整价格表](regional-price-matrix.md)，机器可读草案见[价格JSON](regional-expansion-prices.json)。新价格不改变套餐权益、SKU或原有计费周期，不新增`pro_new`。

| 对象 | 价格规则 |
| --- | --- |
| 第一、第二组新购及新收费报价 | 全部使用对应地区新表金额，Pro只用新Pro列 |
| 本次需求确认时线上已购买Pro的当前已付周期 | 保留真实旧金额、权益和原周期结束时间 |
| 上述线上Pro下个付费周期 | 月付在下次月续费、年付在下次年度续费切新价 |
| Basic、Plus、付费Trial、Study Pass和会员额外包 | 没有当期保旧价资格；上线后的报价和后续应付使用新金额 |
| 历史已付账单 | 保留付款事实；不因采用新价追溯重算、自动补扣或退款 |

Trial不是“已购买Pro”的例外；首段已支付事实不改，7天结束后转正使用新Pro月价。Study Pass按自身自然月合同处理，不继承Pro保旧价资格。旧独立额度SKU与三个会员额外包不同，新表没有提供其对应金额时列待核对，不套用addon金额，也不新增保旧价例外。

## 3. 选价和线上Pro换价

```text
独立新购：可信国家 → 定价区＋币种 → 新价格版本 → SKU Price
已有合同的新收费动作：原合同区＋币种 → 新价格版本 → 目标SKU Price
符合资格的线上已购Pro当前周期：保留实际旧Price和已付金额
该Pro下个付费周期：合并既有Schedule，采用同区同币种新价格
```

线上Pro资格来自本次需求确认时的生产付款／合同快照，固定记录名单与确认时间，不能仅凭旧Price、Pro权益标签或沙盒数据授予。用户旅行不改变合同区和币种。区归属不明或缺同币种目标时列待处理，不按当前IP猜测、不自动换币；配置未齐不能作为长期保旧价规则。

例如：已核实且符合线上Pro资格的巴西合同，本期已付R$399.90，原周期结束后续费R$60.99，本期不退差价。即使该用户此时购买会员作业额外包，也按新表R$19.99报价，不能把Pro保旧价资格扩展到额外包。第二组美国用户新购Pro直接使用$29.99，无需等待第二批开放。

已有试用转正、预约降级和取消必须保留。已预约从Pro降到Basic的，下期使用新Basic金额；已取消续费的不被重开。只更新销售目录不等于Pro已安排下期换价，必须逐合同执行、记录并回读。

## 4. 实现与配置边界

复用既有Product，按“区＋SKU”配置Price；11个SKU对应176条候选Price，会员／Trial／额外包的620个固定金额已从表中录入。Study Pass已覆盖全部63地区、62个区币种组合，本轮补齐原缺失52组合且原10组合金额保持；全量682个主单位金额已齐。Pass按USD0.99×倍率×固定参考，低额取USD0.60缓冲、HKD4参考折算及已公布同币种结算最低金额的最大参考值后向上取整，计算依据见[Pass测算](study-pass-pricing.md)。所有金额仍需账户配置与真实扣款验证，TND最小单位留待支持核验。

USD也是美国、厄瓜多尔、津巴布韦的实际销售币种，必须使用各自定价区的新表USD金额；其余区的技术性USD默认金额不得作为销售回退。GHS/TND支持、补充表USD替代建议、TND最小单位及Pass实际扣款列为配置／验证待办，不能因此将地区移出本次范围。

后端统一选择Price、金额、币种，并用Price注册表处理新旧回调；现有订单`biz_context`合并快照，不为版本新建表。前端消费后端报价，价格或Trial转正目标变化时要求再次确认。账号分别披露实际本期付款、已安排下期金额和生效日期。
